# Vision

## Working name

`open-personal-tracking` is a temporary project name.

The product name is intentionally undecided.

The working name should not become part of permanent user-facing contracts unless explicitly adopted later.

## Vision

open-personal-tracking exists to make personal tracking durable, portable, private, and independent from the survival of any single service.

People should be able to build years or decades of personal history without accepting that a company, account, API, subscription, acquisition, or shutdown controls whether that history remains accessible.

The project aims to become an open platform for tracking the things people watch, read, play, listen to, visit, learn, collect, and experience.

## Core idea

> What you track is yours.

The application should be useful even if:

- there is no account
- there is no Internet connection
- the official network is unavailable
- a metadata provider disappears
- the original maintainers stop working on the project

## Long-term direction

The project may eventually consist of:

- an end-user application
- a documented data format
- importers
- catalog providers
- SDKs
- optional network services
- open aggregate datasets
- self-hostable components
- third-party compatible applications

The application is not necessarily the entire product.

The durable data model and ecosystem may become equally important.

## What the project should not become

open-personal-tracking should not become:

- a mandatory cloud service
- an account-first product
- a closed social network
- a proprietary data silo
- a tracker where export is a premium feature
- a service that stops functioning when servers are unavailable
- a system that optimizes engagement at the expense of user control
