# Localization

## Goal

The project should be usable internationally without embedding English-specific assumptions into the domain model.

## Source language

Initial source language: English.

This may be revisited through governance.

## Translation workflow

Translation infrastructure should support community contribution.

Do not hard-code user-facing strings inside business logic.

## Locale-sensitive data

Handle carefully:

- dates
- numbers
- pluralization
- title translations
- reading direction
- regional release information

## Catalog metadata

A translated title is not necessarily a replacement for an original title.

Preserve language and regional context where available.
