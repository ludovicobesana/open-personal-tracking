# Maintainers

## Purpose

This file records project stewardship and areas of responsibility.

It should be updated publicly as maintainership changes.

## Current maintainers

To be defined.

## Responsibilities

Maintainers may be responsible for:

- pull request review
- releases
- issue triage
- governance
- security coordination
- community moderation
- package publishing
- infrastructure administration

## Areas of ownership

Future ownership areas may include:

- Core domain
- Storage and migrations
- Backup and restore
- Web
- Android
- iOS
- Providers
- Importers
- Network
- Design
- Accessibility
- Documentation
- Community

## Bus factor

Critical project capabilities should not depend indefinitely on one person.

As the project grows, at least two trusted maintainers should have access to critical release and infrastructure resources where practical.
