# Weekly open-personal-tracking Community Call

## Purpose

The weekly call is a public working session for issue triage, contributor coordination, product discussion, and RFC review.

It is not a replacement for asynchronous decision-making.

## Cadence

Once per week, 13:00-14:00 (UTC).

Rotate or periodically reconsider the time if the community becomes international.

## Duration

60 minutes.

## Joining

- Discord: https://discord.gg/6CjFPH55Rv

## Agenda template

```markdown
# open-personal-tracking Weekly Call - YYYY-MM-DD

## Attendees

## New contributors

## Critical bugs / data safety

## Issue triage

## Pull requests needing help

## RFCs

## Product / UX

## Good first issues

## Decisions

## Action items

## Open floor
```

## Before the call

Create or update a public GitHub Discussion or issue containing:

- date
- joining information
- agenda
- issues to review
- RFCs to review
- place for community agenda requests

## During the call

Prefer discussing items that benefit from synchronous conversation.

Do not spend the call reading issue descriptions aloud.

## After the call

Within the same day, publish:

- decisions
- unresolved questions
- action items
- owners where volunteered
- links to newly created issues or RFCs

## Decision rule

A spoken decision is not final until it is written down in the repository.

## Recording

If calls are recorded, make recording explicit before participation and publish a clear retention policy.

Written notes remain the canonical project record.
