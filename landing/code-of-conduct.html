Community

Code of Conduct

Our standard

open-personal-tracking aims to maintain a constructive technical community where people can disagree strongly about ideas without making participation hostile.

Expected behavior includes:

  • respectful technical disagreement
  • useful criticism
  • giving contributors room to learn
  • acknowledging uncertainty
  • documenting reasoning
  • avoiding personal attacks
  • avoiding harassment
  • respecting boundaries

Unacceptable behavior

Examples include:

  • harassment
  • threats
  • targeted insults
  • discriminatory abuse
  • sustained bad-faith disruption
  • publishing private information without permission
  • sexual harassment
  • deliberately sabotaging community spaces

Enforcement

Maintainers may:

  • request behavior changes
  • remove content
  • restrict participation
  • temporarily suspend participation
  • permanently remove participants in severe cases

Moderation actions involving maintainers should be reviewable by another maintainer whenever possible.

Scope

This policy applies to official open-personal-tracking community spaces and project-related interactions, including:

  • GitHub Issues, Discussions, and Pull Requests
  • the Discord server
  • the weekly community call
  • any other space where someone represents the project or its community

Everyone participating in a GitHub Discussion or the weekly call is expected to have read and follow this Code of Conduct. Maintainers hosting the weekly call are responsible for enforcing it in real time.

Reporting

A private conduct-reporting channel should be established before the community grows beyond the initial maintainers.

Reports should be handled confidentially and with the minimum disclosure necessary for resolution.
